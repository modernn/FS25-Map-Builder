# FS25 Dry

Run `.\scripts\fs25.ps1 run <slice-name> --dry-run`. If no slice is provided, run `.\scripts\fs25.ps1 list`.

This is the exception where showing the generated wrapper command is expected, because the user asked for a dry command preview.
